# Pistons HUB - Instalador Automático 📥

Este instalador gráfico premium configura de forma 100% autônoma o ecossistema do **Pistons Hub** e suas dependências gráficas estruturais (`PyQt6`, `pywebview`, `psutil`) no Ubuntu 24.04, alocando-o no diretório padrão do sistema `/opt/Pistons-App` e executando a autoexclusão limpa ao finalizar.

## 🚀 Instalação Rápida (Linha Única)

Para baixar e iniciar a instalação gráfica em tela cheia na sua máquina de destino, abra o terminal do Ubuntu e execute o comando mestre abaixo:

```bash
cd ~ && rm -rf instalador_temp && mkdir instalador_temp && cd instalador_temp && wget -q https://githubusercontent.com && wget -q https://githubusercontent.com && chmod +x instalar.sh && ./instalar.sh
```
